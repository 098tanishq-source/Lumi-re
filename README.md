# Lumière Fine Dining

Lumière is an elegant, dark-romantic restaurant web concept built with pure HTML, CSS, and JavaScript.  
It presents a fine-dining culinary brand with full menu categories, drink pairings, gallery, guest reviews, animated stats, and instant WhatsApp table reservation triggers.

## Live Demo
👇  
https://098tanishq-source.github.io/Lumi-re/

## Features

- Responsive luxury restaurant landing page
- Categorized menu section (Starters, Mains, Desserts)
- Signature drinks & cocktails showcase
- WhatsApp reservation & table booking flow
- Photo gallery and press quotes
- Operational hours and location details
- Interactive design breakdown modal
- Mobile-first layout
- Built in a single `index.html` file

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts (Playfair Display, Manrope)
- GitHub Pages
